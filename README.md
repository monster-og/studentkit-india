# 🎓 StudentKit India

> **All-in-One Academic, Exam & Utility Tools for Indian Students**

StudentKit India is a free, fast, and mobile-friendly web app designed specifically for Indian students. It provides a collection of useful calculators and tools to simplify academic life.

---

## 🚀 Live Demo

🌐 [Visit StudentKit India](https://monster-og.github.io/studentkit-india)

---

## 🛠️ Tools Available

### 📊 Calculators
| Tool | Description |
|------|-------------|
| **Percentage Calculator** | Calculate percentage from marks obtained |
| **CGPA Calculator** | Convert CGPA to percentage & vice versa |
| **Attendance Calculator** | Check if you can bunk or need to attend classes |
| **Grade Calculator** | Find your grade based on marks |
| **Marks Calculator** | Calculate marks needed to pass/score target |
| **Age Calculator** | Calculate exact age from date of birth |
| **EMI Calculator** | Calculate loan EMI easily |
| **Unit Converter** | Convert between common units |

### 🖼️ Media Tools
| Tool | Description |
|------|-------------|
| **Image Compressor** | Compress images without losing quality |
| **Image Resizer** | Resize images to desired dimensions |

## ⚡ Run Locally

```bash
# Clone the repository
git clone https://github.com/monster-og/studentkit-india.git

# Go into the directory
cd studentkit-india

# Run with Python
python -m http.server 3000

# Open in browser
# http://localhost:3000
```
